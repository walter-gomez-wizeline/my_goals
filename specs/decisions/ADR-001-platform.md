# ADR-001 — Responsive web platform

Date: 2026-10-26. Status: accepted by user instruction.

## Context and decision

The user wants the first version on mobile and desktop. Build a responsive web application with the same functional flows at both sizes.

## Consequences

Interaction must support touch and keyboard. Verify the complete gym flow at both sizes. This decision does not define storage, hosting, authentication, PWA installation, offline use, or synchronization. ADR-002 subsequently records the account/shared-persistence decision; ADR-003 remains pending.
